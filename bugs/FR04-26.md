# FR04-26 - Stored profile name executes an HTML event handler in Web greeting

| Field | Value |
|---|---|
| Finding | FR04-26 |
| Requirement | FR04 |
| Severity | High |

## Summary

Stored profile name executes an HTML event handler in Web greeting. This issue covers the specific condition represented by A-UI-09.

## Environment

- Baseline: `85af3ba875c88283615e22cb108f13e2fccaf0e9`.
- Selected requirement: FR04; oracle: SEC-04 user input must be escaped.
- Interface: Browser UI via Playwright.
- Severity: High.
- Isolated demo source/database; no fix applied to the original SUT.

## Preconditions

Start a disposable copy of the fixed baseline. For API calls obtain a JWT through `POST /api/login`: regular user `test@eshop.com` / `Test1234!`, admin `admin@eshop.com` / `Admin123!`. These are public demo fixtures, not personal credentials. Use JSON requests and the role shown in the captured request. The server clock for API cases is fixed at `2026-10-19T08:00:00.000Z`.

Restore the target account to role=user, name=Test User, phone=0912345678 and shipping_address=1 Test Street. Keep fields other than the target condition nominal. Do not restore the fixture between the write and its readback.

### Controlled fixture

Using a regular-user JWT, PUT `/api/users/me` with the canary in name, phone=`0912345678` and shipping_address=`1 Test Street`. The backend accepts this complete payload. Open Web `/profile` using the same identity. The injected event only sets a DOM marker and replaces its own image; it performs no credential access or exfiltration.

## Steps to reproduce

1. Store the documented harmless img/onerror canary as the demo profile name; open Web /profile with that user and observe the header DOM.
2. Record the actual DOM, handler output or state transition.
3. Compare the observation and its scope with the expected criterion below.

## Expected result

SEC-04: user-controlled name is escaped; an HTML event handler cannot execute.

## Actual result

```json
{
  "at": "2026-10-20T07:43:52.151983+00:00",
  "observed": {
    "stored_name": "<img src=x onerror=\"document.documentElement.dataset.profileCanary='executed';this.outerHTML='<b>PROFILE_CANARY_EXECUTED</b>'\">",
    "canary_executed": true,
    "persisted_via": "Authenticated PUT /api/users/me",
    "update_response": {
      "message": "Profile updated"
    },
    "greeting": "EShop\nGiỏ hàng\nChào, PROFILE_CANARY_EXECUTED\nThoát",
    "scope": "Harmless DOM canary only; no token theft tested."
  },
  "expected": "SEC-04: user-controlled name is escaped; an HTML event handler cannot execute.",
  "precondition": ""
}
```

## Impact

A stored name executes an HTML event handler inside the authenticated Web origin. Only a harmless marker was executed; token theft and propagation to other identities were not attempted.

## Root cause

Header renders user.name with dangerouslySetInnerHTML.

[Affected source at the fixed baseline](https://github.com/tkob-team/eshop-sut/blob/85af3ba875c88283615e22cb108f13e2fccaf0e9/frontend-web/src/App.jsx).

## Suggested correction

Render user-controlled text through normal React interpolation. The test does not access credentials or exfiltrate data.
