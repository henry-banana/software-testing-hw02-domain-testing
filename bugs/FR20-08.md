Mobile positive Add to Cart action is green instead of blue. This issue covers the specific condition represented by D-UI-15.

## Impact

The product-detail acceptance or display criterion is violated for the documented input. Only the feedback and cart state visible in the supplied captures are claimed.

## Root cause

The positive action is assigned the greenButton style rather than the blue primary-action style.

[Affected source at the fixed baseline](https://github.com/tkob-team/eshop-sut/blob/85af3ba875c88283615e22cb108f13e2fccaf0e9/frontend-mobile/App.js).

## Suggested correction

Apply the specified blue action style. This criterion was reviewed from an existing native capture, not a new device session.
